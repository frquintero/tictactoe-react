# Simple Dark Mode Toggle Demo

This project demonstrates a basic implementation of a dark mode toggle using HTML, CSS, and JavaScript.

## How to Use

1.  Clone or download this repository.
2.  Open the `index.html` file in your web browser.
3.  Click the "Toggle Dark Mode" button to switch between light and dark themes.

## Files

*   `index.html`: The main HTML structure.
*   `style.css`: Contains the styles for both light and dark modes.
*   `script.js`: Handles the logic for toggling the theme.
